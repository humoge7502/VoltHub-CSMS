01 · THE PROBLEM

Three hard problems,
wearing one coat.

01

Double booking

Two drivers reserve the same connector in the same second. A check in application code is a race with a delay fuse.

cost of getting it wrong · a connector sold twice
02

Billing drift

Money must be billed once, and only once. Retries, replays and restarts are exactly where invoices double.

cost of getting it wrong · a driver billed twice
03

Telemetry flood

Ninety percent of the rows are immutable meter ticks. A row-store asked to answer “last seven days by hour” will fold.

cost of getting it wrong · analytics that lie
None of these is a workflow problem. All three are a transaction problem.

into the database
