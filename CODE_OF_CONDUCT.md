# Code of Conduct

## Our standard

Be precise, be honest, be useful. This repository treats technical disagreement
as fuel — critique the code, the design, or the claim, never the person.

Examples of behavior that makes this repo work:

- Naming the trade-off you would have chosen differently, and why
- Reproducing a bug before reporting it (or saying plainly what you could not reproduce)
- "This is wrong, here's the failing case" — the most valuable comment there is
- Citing receipts: test output, benchmark numbers, ADR context

Examples of behavior that is not tolerated:

- Harassment, insults, or personal attacks of any kind
- Trolling, bad-faith argument, or publishing others' private information
- Claims without evidence — this codebase runs on receipts; bring yours

## Scope

Applies to the repository, its Issues, PRs, Discussions, and any project space
(online or offline) where you represent the project.
